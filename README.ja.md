# MPX68K for iOS

[English](README.md) | 日本語

**iPhone / iPad** 向けのシャープ X68000 エミュレータです。px68k のエミュレーションコアに、UIKit・SpriteKit・Swift で作った iOS ネイティブの画面を組み合わせています。

## 主な機能

- px68k コアと C68K（M68000 CPU コア）による X68000 のエミュレーション。
- フロッピーディスク `.dim` `.xdf` `.2hd` `.d88` `.hdm`（2 ドライブ）。
- ハードディスクイメージ `.hdf` `.hds`。
- アプリの Documents フォルダにあるイメージのディスク一覧と、ファイル App などからの取り込み。
- タッチ操作: 8 方向の仮想ジョイスティックと A/B ボタン、トラックパッド式のマウス、画面上の X68000 キーボード。
- ハードウェアキーボードと対応するゲームコントローラ。
- FM 音源と ADPCM。ROM を用意すれば内蔵 SC-55 または MT-32 / CM-32L で MIDI を鳴らせます。外部 MIDI にも対応。
- iPhone / iPad の向きや使える表示領域に合わせた画面と操作系の配置。
- ディスクメニューから CPU クロック（1〜50 MHz、既定 24 MHz）と Turbo / No-Wait の速度モードを選択。
- ジョイスティック 1 の CYBER STICK（アナログモード）エミュレーション（ディスクメニューで選択）。

### iPhone Duo

iPhone Duo（iOS 27.1 以降）では、持ち方に合わせて画面構成が変わります。

- **閉じた状態・全開:** 全画面表示で、タッチ操作を重ねて表示。
- **L 字・ノート PC 持ち:** 上半分に X68000 の画面、下半分は X68000 キーボード・仮想パッド・トラックパッド・サウンドモニターから選択。キーボードの上のランプ列に FDD0 / FDD1 のアクセス、HD BUSY、キーボード LED（かな・ローマ字・コード入力・CAPS・INS・ひらがな・全角）を表示。
- **本の持ち方:** 片側に画面、もう片側にドライブベイ（フロッピー 2 台とハードディスク。アクセスランプ、ディスク名、取り出しボタン。スロットをタップするとそのドライブのディスクメニュー）。ドライブの下には、ゲームが MIDI を送っている間は内蔵 SC-55 / MT-32 の液晶、それ以外は小さな OPM モニターを表示。
- **ヒンジ:** 約 50° より閉じるとブラウン管の電源を切ったような演出になり、開き直すと画面が戻ります。CYBER STICK を選んでいるときは、ヒンジの角度がスロットルになります（80° 以下でいちばん手前、170° 以上でいちばん前）。

### サウンドモニター

MMDSP 風の OPM（YM2151）と ADPCM のモニターです。FM 8 チャンネルそれぞれの音名、7 オクターブの鍵盤、ピーク保持つきレベルメーター、パン、アルゴリズム（チャンネル 8 がノイズのときは `NOIS`）と、ADPCM の再生状態、LFO、ADPCM のサンプリング周波数を表示します。FM 音源エンジンは内部状態を出さないので、レベルはレジスタへの書き込みから推定しています。

## 動作環境

- **iOS / iPadOS 17.0 以降**の iPhone / iPad（arm64）。iPhone Duo の姿勢別レイアウトとヒンジの機能は **iOS 27.1 以降**。
- ソースからビルドするには **Xcode 27.1** の入った Mac（[ソースからのビルド](#ソースからのビルド)を参照）。
- X68000 の純正システム ROM。このリポジトリには含まれていません。

## ROM とディスクイメージの用意

次の ROM ファイルが必要です。

| ファイル | 内容 |
| --- | --- |
| `IPLROM.DAT` | X68000 の IPL ROM |
| `CGROM.DAT` | キャラクタジェネレータ ROM |

初回起動時、足りない ROM があると選択画面が出ます。ファイル App で次の場所にコピーしてもかまいません。

```text
このiPhone内（またはこのiPad内）
└── MPX68K for iOS
    └── MPX68K
```

ディスクイメージも同じ `MPX68K` フォルダに置きます。アプリのディスクメニューから選ぶか、**その他の場所…** でファイル App などから取り込めます。フロッピーとハードディスクは拡張子で判別します。

ROM には著作権があります。使用が認められた入手元のものだけを使ってください。ROM イメージをこのリポジトリに追加したり、アプリと一緒に配布したりしないでください。

### 内蔵 MIDI 音源（任意）

内蔵音源を使うには、ROM ファイルを同じ `MPX68K` フォルダに置いてアプリを再起動します。

- **SC-55:** `sc55_rom1.bin` `sc55_rom2.bin` `sc55_waverom1.bin` `sc55_waverom2.bin` `sc55_waverom3.bin` の 5 本。
- **MT-32 / CM-32L:** 対応するコントロール ROM と PCM ROM。

MT-32 の ROM は内容で判別するので、ファイル名は問いません。MIDI メニューで「外部 MIDI」「内蔵 SC-55」「内蔵 MT-32」を切り替えます。これらの ROM も含まれていません。

### メインメモリ

実機と同じく、メインメモリの容量は SRAM の設定値で決まります（変更するまでは 1 MB）。MXDRV などがメモリ不足を訴えるときは、`SWITCH.X` で容量を増やしてリセットしてください。

## 操作

- **仮想ジョイスティック:** 8 方向と A/B ボタン。方向パッドをカーソルキーとして使う設定もあります。
- **タッチマウス:** 1 本指ドラッグでポインタ移動、タップで左クリック、2 本指タップで右クリック、長押しからドラッグで左ボタンを押したまま移動。対応するポインティングデバイスをつないだ iPad ではホバーも使えます。
- **画面上のキーボード:** ファンクション・編集・カーソル・修飾キーを含む JIS 配列の X68000 キーボード。
- **ハードウェアキーボード・ゲームコントローラ:** 対応する機器をつなぐと、タッチ操作の代わりに使えます。
- **CYBER STICK:** スティックとトリガー A / B は仮想パッドかゲームコントローラから入力します。iPhone Duo ではスロットルがヒンジに連動し、変わると THROTTLE の表示が少しの間出ます。それ以外の端末ではスロットルは中央のままです。

## ソースからのビルド

1. リポジトリを取得します。

   ```bash
   git clone https://github.com/YosAwed/MPX68K-iOS.git
   cd MPX68K-iOS
   ```

2. **Xcode 27.1** で `MPX68K iOS.xcodeproj` を開きます。
3. **MPX68K iOS** スキームと、iPhone / iPad のシミュレータまたは接続した実機を選びます。
4. ビルドして実行します。実機に入れるには Apple Developer アカウントでの署名が必要な場合があります。

ビルドには Xcode 27.1（iOS 27.1 SDK）だけを使ってください。iOS 27.0 SDK でもエラーなくビルドできますが、iPhone Duo の配置とヒンジのコードが外れ、半開きでも全画面のままになります。`xcode-select` が別の Xcode を指している場合は、コマンドラインで `DEVELOPER_DIR` を指定します。

```bash
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer xcodebuild \
  -project "MPX68K iOS.xcodeproj" -scheme "MPX68K iOS" -configuration Debug \
  -destination 'generic/platform=iOS Simulator' build
```

プロジェクトファイルは `tools/generate_ios_project.py` で生成しています。ソースファイルを追加・削除したら再実行してください。

iPhone Duo シミュレータを使うには、iOS 27.1 のシミュレータランタイムを入れて「iPhone Duo」のデバイスを作ります。Debug ビルドをシミュレータで動かすと、ヒンジの代わりに画面左上に HINGE スライダーと CRT ボタンが出ます。セットアップの詳細とシミュレータの癖は [docs/IOS_HANDOFF.md](docs/IOS_HANDOFF.md) を参照してください。

## コアのテスト

エミュレータコアのテストは Xcode も ROM もなしで実行できます。

```bash
make -C tests/core
make -C tests/mt32
make -C tests/sc55
```

`tests/mt32` と `tests/sc55` には実 ROM で確かめる `rom` ターゲットもあります（例: `make -C tests/mt32 rom ROM_DIR=...`）。

## ディレクトリ構成

- `MPX68K iOS.xcodeproj` — iPhone / iPad アプリのプロジェクト。
- `X68000 iOS/` — iOS アプリのライフサイクル、画面配置、タッチ操作、ディスク一覧、iPhone Duo の姿勢別パネル（`DuoPanels.swift`）、サウンドモニター（`SoundMonitorView.swift`）。
- `X68000 Shared/` — 共有の Swift 部分とエミュレータのコード。
- `X68000 Shared/px68k/` — X68000 ハードウェアのエミュレーションコア。
- `c68k/` — M68000 CPU コア。
- `tests/` — エミュレータコアと内蔵 MIDI 音源のホスト側テスト。
- `tools/` — プロジェクト生成スクリプトと確認用ディスクのソース（CPU 速度、CRT モード、CYBER STICK など）。
- `docs/` — iOS 移植の設計メモ（[IOS_PORT_PLAN.md](docs/IOS_PORT_PLAN.md)）と開発の引き継ぎメモ（[IOS_HANDOFF.md](docs/IOS_HANDOFF.md)）。

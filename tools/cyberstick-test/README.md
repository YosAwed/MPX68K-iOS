# cyberstick — CYBER STICK（アナログモード）確認ディスク

MPX68K の CYBER STICK エミュレーション（ジョイスティック 1、アナログモード）を確認する、
Human68k 不要のセルフブート XDF です。IPLROM の IOCS だけで動き、著作物は収録していません。

シャープのドライバと同じ手順で読みます: REQ（PPI ポート C ビット 4）を下げてから 12 ニブルを、
2 つずつ「L/H（ポート A ビット 5）が L → ACK（ビット 6）が L → 読む → L/H が H → ACK が L → 読む」で読み、
8 ニブル読んだところで REQ を上げます。読む間は割り込みを止めます。

| 行 | 表示 |
|---|---|
| Y / X | スティック（$00 = 上・左、$80 = 中央、$FF = 下・右）。仮想パッドの十字は端まで倒した値になる |
| THROTTLE | スロットル（$00 = いちばん前、$FF = いちばん手前）とバー。iPhone Duo ではヒンジの角度（80° で $FF、170° で $00） |
| Nibbles | 受け取った 12 ニブル |
| A B C D | 1 ニブル目（0 = 押している）。仮想パッドの A / B がビット 3 / 2 |
| Reports / timeouts | 読めた回数と、途中で応答がなくなった回数 |

## 使い方

1. ディスクメニュー → ジョイスティック → 「CYBER STICK（アナログ）」を選ぶ
2. `cyberstick.xdf` を FDD0 に入れて起動する（HDD は外すか、ブート順を FD に）

「標準ジョイスティック」のままだと、毎回 timeouts が増えます（アナログの応答がないため）。

## ビルド

```bash
./build.sh
```

GNU binutils (m68k) が必要です。Homebrew の elf2x68k ツールチェーンなら
`PREFIX=m68k-xelf- ./build.sh`。
